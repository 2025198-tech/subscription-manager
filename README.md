# 🎬 정기 구독 관리 매니저 (Subscription Manager)

Google Apps Script(GAS)와 HTML/CSS/JS로 구현된 **개인 맞춤형 구독 관리 웹앱**입니다.

## 📌 주요 특징
- **결제일 달력 선택기**: Native Date Picker 지원
- **실부담금 계산기**: 파티원 N분의 1 자동 정산 및 월간/연간 지출 통계
- **데이터 보안**: 구글 드라이브 내 구글 시트에 데이터가 보관되어 개인정보 안전 유지

## 🔧 설치 및 배포 절차
1. 구글 드라이브에서 새 **Google Sheet**를 생성합니다.
2. 상단 메뉴 **확장 프로그램 > Apps Script**로 이동합니다.
3. 본 저장소의 `Code.js` 내용을 `Code.gs`에, `Index.html` 내용을 `Index.html` 파일에 복사합니다.
4. 우측 상단 **배포 > 새 배포**를 선택합니다.
   - **유형**: 웹앱 (Web App)
   - **실행 사용자**: 나 (Me)
   - **액세스 권한**: 나만 또는 모든 구글 사용자
5. 생성된 웹앱 URL을 통해 브라우저 및 모바일에서 접속하여 사용합니다.
